# TinDog

A responsive marketing landing page for TinDog, a playful dating app concept for dogs.

**Live Demo:** [https://durnazeynalli.github.io/tindog/](https://durnazeynalli.github.io/tindog/)

## Overview

TinDog is a front-end landing page created using HTML5 and CSS3. It showcases product features, user testimonials, press mentions, pricing options, and mobile download call-to-actions within a clean, responsive layout designed for both desktop and mobile screens.

## Features

- **Hero Section:** Product pitch with app download calls-to-action and mobile mockups.
- **Feature Highlights:** Highlights core product benefits and value propositions.
- **Testimonial Carousel & Press Coverage:** Customer quotes and press logos (TechCrunch, Business Insider, Mashable, TNW).
- **Responsive Design:** Styled to adapt across different screen sizes and devices.

## Tech Stack

- **HTML5**
- **CSS3**

## Getting Started

No build tools or package managers are required to run this project locally.

1. **Clone the repository:**
   ```bash
   git clone https://github.com/durnazeynalli/tindog.git
   cd tindog
   ```

2. **Open the project:**
   - Open `index.html` directly in any web browser, or
   - Serve it using a local HTTP server such as VS Code Live Server or Python:
     ```bash
     python3 -m http.server 8000
     ```
     Then visit `http://localhost:8000` in your browser.
